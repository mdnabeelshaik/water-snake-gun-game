
# Water–Snake–Gun Game 🐍💧🔫

A simple Python game inspired by the classic **Snake–Water–Gun** game.

The player chooses one option, and the computer randomly chooses another. The program compares both choices and decides the winner.

## Game Rules

| Choice | Beats |
|---|---|
| Snake 🐍 | Water 💧 |
| Water 💧 | Gun 🔫 |
| Gun 🔫 | Snake 🐍 |

- If both the player and computer choose the same option, the game is a **draw**.
- The game runs for **4 rounds**.

## Choices

Enter one of the following when asked:

- `s` for Snake
- `w` for Water
- `g` for Gun

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file using:

```bash
python main.py
```

If the file has a different name, replace `main.py` with your file name.
